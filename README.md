## Overview

Path of Building 2 is a community-maintained fork of Path of Building, the comprehensive offline build planner for Path of Exile. It calculates DPS, effective HP, resistances, and all other character statistics from a full skill tree and gear configuration, supports all current league mechanics, and enables importing live characters for theorycrafting tweaks.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Path of Building 2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full Stat Calculation** | Calculates DPS, EHP, resistances, and all character stats offline |
| **Skill Tree Support** | Full passive skill tree including all cluster jewels and keystones |
| **Gear Simulation** | Import PoB codes or manual gear entry for complete build testing |
| **Character Import** | Import live characters from Path of Exile servers for analysis |
